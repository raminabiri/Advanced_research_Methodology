# کتابخانهٔ کوچک تمرین ابزارهای برخط

چهار رکورد مربوط به سه مقالهٔ واقعی است؛ EX04 تکرار عمدیِ EX01 برای تمرین حذف تکرار است. این فایل نتیجهٔ یک جست‌وجوی جامع نیست. شناسه‌های EX شناسهٔ تمرین‌اند، نه شناسهٔ رسمی مقاله. متاداده کوتاه شده و تنها نام نویسندهٔ نخست آمده است.

پرسش انتخاب **آموزشی**: مرورهای دارای متاآنالیز دربارهٔ مداخلهٔ ورزش و نشانه‌های افسردگی؛ متاآنالیز شبکه‌ای نیز پذیرفته می‌شود. این تمرین نرم‌افزار، اجرای کامل یک مرور یا ثبت واقعی نیست.
