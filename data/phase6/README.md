# داده و فرادادهٔ فاز بار بیماری

کدهای M24، M25 و M27 عددهای **ساختگی** تولید می‌کنند. این فایل‌ها دادهٔ واقعی ایران یا خروجی GBD نیستند. دادهٔ واقعی تمرین مقاله‌خوانی، جدول‌ها و چکیدهٔ مقاله‌های ارجاع‌شده در پایان درس‌هاست؛ نقل عدد از مقاله با دریافت CSV از ابزار فرق دارد.

برای دانلود واقعی، این برگه را همراه ورودی خام نگه دارید:

| فیلد | نمونهٔ درخواست؛ اجرا نشده |
|---|---|
| نسخه | GBD 2023، اگر در حساب در دسترس باشد |
| مکان | Iran و یک کشور مقایسهٔ انتخابی |
| علت | یک علت مشخص با کد و سطح روشن |
| measure | DALYs |
| metric | Number و Rate در درخواست‌های مشخص |
| age | All ages برای شمار؛ Age-standardized برای نرخ مرجع |
| sex | Both یا جنس‌های جدا با هدف ازپیش‌تعریف‌شده |
| year | سال‌های مورد پرسش از همان نسخه |
| زمان دریافت | در اجرای واقعی تکمیل شود |
| URL و شرایط کاربرد | نشانی و متن شرایط نسخهٔ جاری |
| فایل خام و SHA256 | پس از دریافت ثبت شود |
| نگاشت ستون‌ها | نام اصلی، نام پاک‌سازی‌شده، تعریف و مقیاس |

هیچ فایل دانلودشدهٔ واقعی GBD به این پوشه افزوده نشده است. فایل زیر فقط برای تمرین خواندن قالب است.
