# پروندهٔ پیوستهٔ مبانی: ورزش و افسردگی

شش رکورد RIS شامل پنج گزارش یکتا است؛ Noetel تکرار عمدی دارد. سه گزارش مرور و دو گزارش کارآزمایی‌اند. انتخاب این مجموعه محدود، تمرین ثبت و غربالگری است و خروجی جست‌وجوی جامع نیست.

`blumenthal2007_extraction.csv` چهار بازوی واقعی کارآزمایی را از متن نویسندگان ثبت می‌کند: n تخصیص، میانگین و SD تغییر HAM-D در ۱۶ هفته. خلاصه‌ها تغییرند، نه نمرهٔ پایان. n تخصیص با n صریحِ چاپ‌شده برای هر خلاصه یکی فرض نشده است؛ برای بازتحلیل خامِ نمونه، فرضِ استفاده از n تخصیص در جامعهٔ ITT/LOCF به‌طور آشکار ثبت شده است.

`illustrative_unadjusted_contrast.csv` محاسبهٔ آموزشی با همان فرض است؛ برآورد تعدیل‌شدهٔ نویسندگان نیست. در ارزیابی خطر سوگیری، LOCF را به معنی حل کامل گمشدگی تفسیر نکنید. نوع جامعهٔ تحلیل و حساسیت به فرضِ مخرج بخشی از تصمیم روش است.

منبع: [نسخهٔ نویسندگان در دانشگاه Duke](https://people.duke.edu/~mababyak/papers/blum_ex_dep_2007.pdf)، بخش‌های Treatment،Statistical Analysis وResults. منابع و فیلم‌های درس در پایان lesson.md ماژول مربوط قرار دارند.
