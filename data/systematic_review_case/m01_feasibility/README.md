# داده و رد اجرای نمونهٔ M01

این پوشه همراه یک **مرحلهٔ آموزشیِ امکان‌سنجی** است، نه خروجی جست‌وجوی جامع یا مرور کامل تازه.

| فایل | محتوا و منشأ |
|---|---|
| [known_reviews_filled.csv](known_reviews_filled.csv) | جدول پرشدهٔ سه مرور واقعی Noetel،Singh وCooney؛ ستون ارتباط با پرسش و تصمیم بعدی، قضاوت آموزشی نویسنده است |
| [review_inventory_template.csv](review_inventory_template.csv) | فقط سرستون؛ قالب خالی تمرین خواننده است |
| [decision_log_filled.csv](decision_log_filled.csv) | تصمیم‌های آموزشی نویسنده؛ گزارش تصمیم تیم مقاله‌های واقعی نیست |
| [pubmed_pilot_run.json](pubmed_pilot_run.json) | پاسخ واقعی ESearch، شامل عبارت، زمان،count،idlist وquerytranslation؛ دادهٔ پزشکی فردی ندارد |
| [source_checks.json](source_checks.json) | تطبیق DOIها با Crossref برای کنترل عنوان؛ جای ارزیابی کیفیت مقاله نیست |
| [vitamin_d_exercise_facts.csv](vitamin_d_exercise_facts.csv) | دادهٔ واقعی منتخب از Methods چکیدهٔ رسمی دو مرور برای کنترل پاسخ تمرین؛ متن کامل چکیده‌ها بازنشر نشده |

Q01 جست‌وجوی موضوعی در 2026-11-15 است: count=2272، ولی retmax=10 و فقط ده شناسه دریافت شده است. Q02 سه DOI ازپیش‌انتخاب‌شده را جست‌وجو کرده و سه رکورد برگردانده است؛ آن‌ها «سه نتیجهٔ اول Q01» نیستند. عددها در اجرای روز دیگر تغییر می‌کنند. هیچ فرایند غربالگری همهٔ 2272 رکورد در این نمونه انجام نشده است.

سناریوی درمانگاه و محدودهٔ 18 سال به بالا ساختگی/آموزشی‌اند. دادهٔ ردیفی بیمار، جست‌وجوی زندهٔ کامل PROSPERO، نسخهٔ جاری Cochrane و امتیاز ارزیابی رسمی مرورها در این پوشه وجود ندارد و وجودشان ادعا نشده است.

فایل‌ها UTF-8 هستند. به‌جای بازنویسی روی خروجی خام، نسخهٔ تازه با تاریخ و توضیح بسازید. اجرای دوبارهٔ جست‌وجوی نمونه اختیاری است؛ [ابزار ثبت PubMed](../../../tools/m01_pubmed_pilot.py) بدون کلید API، در پوشهٔ خروجی تازه ثبت می‌کند. برای انجام درس، رابط وب PubMed کافی است.

منابع نوشتاری و لینک مستقیم فیلم‌ها **در پایان درس** هستند؛ فایل‌های این پوشه داده و فراداده‌اند، نه فایل جداگانهٔ منابع یا فیلم.
