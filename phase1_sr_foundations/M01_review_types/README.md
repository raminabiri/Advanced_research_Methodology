# P1-M01 — آغاز عملی مرور نظام‌مند

**نمونهٔ بازنویسی برای نظرخواهی نویسنده.** هدف این درس، انجام مرحلهٔ آغاز پروژه است: پرسش اولیه، انتخاب نوع مرور، جست‌وجوی مقدماتی، جدول مرورهای قبلی و تصمیم مستند. این نمونه هنوز الگوی تأییدشدهٔ بازنویسی همهٔ دوره نیست.

**از [متن کامل درس](lesson.md) شروع کنید.** سپس مسیر زیر را دنبال کنید:

| صفحه | محتوا |
|---|---|
| [درس](lesson.md) | آموزش گام‌به‌گام، پرسش‌های مکث، منابع و چهار لینک مستقیم فیلم یوتیوب در پایان |
| [پروندهٔ حل‌شده](worked_example.md) | ورزش و افسردگی؛ از درخواست آموزشی تا تصمیم، با مرورهای واقعی و ثبت اجرای PubMed |
| [کاربرگ](workbook.md) | قالب قابل تکمیل برای پروژهٔ خواننده؛ عمدا خالی است |
| [تمرین](exercises.md) | انتقال روش به پروندهٔ واقعیِ متفاوت و موضوع شخصی |
| [پاسخ تشریحی](solutions.md) | جدول پرشدهٔ ویتامین D، یادداشت تصمیم و معیار ارزیابی |
| [داده و رد اجرا](../../data/systematic_review_case/m01_feasibility/README.md) | جدول‌های پرشده، قالب CSV و ثبت جست‌وجوی مقدماتی |
